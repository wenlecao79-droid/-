# 活动物料设计

原始模板：白纸白马白居易的 Event-KeyVision-designer-物料设计Skill。

## 输入参数

优先使用用户提供的参数；未提供时使用下表默认值。默认值是模板示例，不代表已确认的真实活动信息。用户明确要求的尺寸、配色和行业优先于默认设定。

| 参数 | 含义 | 默认值 |
|---|---|---|
| `brand_name` | 品牌名称 | 英派斯 |
| `event_name` | 活动全称 | 第6代运动健身产品发布活动 |
| `slogan` | 活动口号 | 潮迎亚运 因爱而动 |
| `industry` | 行业/场景 | 新品/发布会 |
| `location` | 举办地点 | 中国·青岛 |
| `date` | 活动日期 | 2026.12.31 |
| `main_color` | 主色调 | 红色/白色 |
| `secondary_color` | 辅助色 | 浅灰/黑 |
| `ip_count` | IP吉祥物数量 | 0个 |

IP数量支持0个或1个；选择0个时，最终提示词明确不包含IP角色。即梦图片4.7是提示词面向的平台与模型，不表示已调用该模型生成图片。


# 指令

根据用户提供的以上参数，生成一段完整、可直接用于即梦AI文生图的高质量提示词。提示词需严格遵循下方模板，并替换所有 `{{变量名}}` 为对应的参数值。输出内容仅包含最终的提示词，无需额外解释。

## 提示词模板

创作一张高完成度的活动品牌视觉系统提案板，主题为“{{slogan}}”，活动是“{{brand_name}}/{{event_name}}”，属于“{{industry}}”。使用即梦图片4.7模型，画幅比例3:4，背景为纯白色，方便抠图，整体呈现多模块品牌系统展示板构图，将不同物料错落有序排列，每样物料有独立展示区域，不要互相重叠挤占展示空间，形成专业设计公司给客户提案的视觉应用总览页效果，集中展示完整的活动视觉系统延展。

**核心视觉系统：**

1. **主Logo/主标题**：醒目的“{{slogan}}”主标题，字体带有设计感，结合几何变形和主题符号，主题下方添加副标题“{{brand_name}}/{{event_name}}”，地点“{{location}}”，日期“{{date}}”，活动口号“{{slogan}}”
2. **辅助图形系统**：围绕主题生成统一的辅助图形，包含线条、几何块、箭头、主题纹样
3. **IP角色**：设计{{ip_count}}潮流可爱的主题IP吉祥物，适合出现在各类物料中

**物料应用展示（完整系统，同一视觉语言）**：  
顶部展示横板21:9的活动主视觉画面，下方物料分为两行，从左至右合理分布，至少包含：大型入口门头装置、签到处、合影美陈、道旗、导视系统、贴纸、产品展示区、周边物料（手环、票券、手提袋等）

**颜色风格**：主色调{{main_color}}，辅助色{{secondary_color}}，整体风格年轻潮流、科技未来，色块清晰对比强烈，高识别度，适合线下落地，整体有清晰留白和层级关系，每个模块体现真实线下应用质感，如亚克力立牌、喷绘布、布旗、地贴、立体字，体现专业设计提案感、完整品牌识别和高商业落地感。
